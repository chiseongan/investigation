# 잠입 수사: 2학년 2반의 일주일

학교폭력 예방 교육(4차시 중 4차시)을 위한 1인용 웹 게임입니다. 전학생으로 위장한 수사관이 월~목요일에 단서를 모으고 금요일에 최종 보고를 합니다. 휴대폰·태블릿에서 약 30분 동안 플레이하도록 만들었습니다.

> 등장하는 학교와 인물은 모두 가상입니다. 로그인과 개인정보 수집이 없습니다.

## 진행 상황
- 1단계: 뼈대 + 월요일 (완료)
- 2단계: 화~목요일, 장소 이동, 단톡방 메신저, 수사 보드 (완료)
- 3단계: 금요일 최종 보고, 엔딩, 되감기, 10년 타임라인, 결과 코드 (예정)
- 4단계: 성능 점검, PWA, 배포, QR (예정)

## 기술
Vite + TypeScript + Svelte 5, 대본은 Ink(inkjs)로 작성했습니다. 아이소메트릭 룸은 DOM과 CSS transform으로 그립니다.

## 실행
```bash
npm install
npm run dev      # 같은 와이파이의 휴대폰에서 http://<PC의 IPv4>:5173
npm test         # vitest
npm run build
```

대본은 `src/story/*.ink`, 방과 장면 배치는 `src/data/rooms.ts`, 단서는 `src/data/clues.ts`에서 고칠 수 있습니다.
